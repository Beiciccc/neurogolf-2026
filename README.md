# NeuroGolf 2026 Project Records

This repository contains a sanitized project mirror for the Kaggle competition
[`neurogolf-2026`](https://www.kaggle.com/competitions/neurogolf-2026). The
competition is complete and this repository is archived as its final record.

Final result:

- Rank: `429 / 3061`.
- Public score: `7374.56`.
- Private score: `7374.56`.
- Best submission reference: `54747177`.

Contents:

- `records/submissions.csv`: public submission outcomes and scores.
- `records/experiments.csv`: compact local experiment metadata.
- `records/best_candidate.json`: latest recorded best public result.
- `records/final_result.json`: verified final competition standing.

Large generated model bundles, local scripts, private logs, credentials, and
internal operating notes are intentionally not included in this public mirror.
